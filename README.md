### Asynchronous FIFO
**Verilog | RTL | CDC | Icarus Verilog | GTKWave**

- Designed an 8-bit, 8-entry asynchronous FIFO operating across independent write and read clock domains.
- Implemented binary and Gray-code read/write pointers for clock-domain crossing.
- Used two-stage synchronizers to transfer Gray-coded pointers between clock domains.
- Implemented FIFO full and empty detection with pointer wraparound handling.
- Developed a self-checking testbench with scoreboard-based data verification.
- Tested reset behavior, full/empty conditions, overflow/underflow attempts, and random simultaneous read/write activity.

**Repository:** [Async-FIFO-Verilog](https://github.com/Abdul-Basith-06/Async-FIFO-Verilog)
